KAPEN 공식 웹사이트 초안

파일
- index.html : 메인 회사/개발자 소개 페이지
- privacy.html : 개인정보처리방침

배포 전 반드시 바꿀 것
1. 문의 이메일은 kapen.apps@gmail.com 으로 반영 완료
2. 사업자명이 사업자등록증상의 영문/한글 표기와 다르면 수정
3. Google Search Console 인증을 받으면 index.html의 google-site-verification 메타 태그 주석을 풀고 인증 코드를 입력
4. 실제 도메인에 배포 후 Search Console에서 소유권 확인

권장
- 자체 도메인 사용 (예: kapen 관련 .com / .kr)
- HTTPS 사용
- Play Console의 조직 웹사이트 주소와 동일한 도메인을 사용
